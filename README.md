# Vehicle_Classification_LLM

## 프로젝트 소개
AI 기반 차량 이미지 분석 & 마케팅 인텔리전스 시스템(딥러닝을 통한 차종 예측과 LLM을 결합한 마케팅 전략 AI 분석 시스템)

## 개발기간
- 2026년 01월 09일 ~ 01월 12일

## 개발 인원
- 1인 개발

## 주요 기능
1. 딥러닝 모델 실험 → 성능 기준 모듈 분리
 - CNN Basic / Deep / Dropout 구조 직접 설계 및 비교 실험
 - ResNet50, MobileNetV2 전이학습 모델 적용
 - Validation Loss / Accuracy 기반 정량적 모델 성능 비교
2. 학습·예측·분석 로직 분리 기반 AI 파이프라인 구축
 - 데이터 전처리 / 모델 학습 / 예측 / 시각화 로직 분리
 - EarlyStopping, ModelCheckpoint를 통한 최적 모델 자동 관리
 - 모델 학습 결과를 기반으로 한 재현 가능한 실험 구조 설계
 - Gradio를 활용한 서비스 레벨 예측 시스템 구현
3. LLM 기반 차량 분석 & 비즈니스 인텔리전스 기능 추가
 - Groq LLM(llama-3.3-70b)을 활용한 AI 해석 레이어 설계
 - 단순 분류 결과가 아닌, 예측 결과를 기반으로 마케팅 제안
4. 비동기 기반 LLM 호출 및 확장성 고려 설계
 - asyncio 기반 비동기 LLM 호출 구조 설계
 - API Key 관리 및 환경 변수 분리(.env)
 - LLM 분석 기능을 클래스로 분리하여 추후 모델 교체 및 기능 확장 용이
