# 🛡️ Vehicle Intelligence: AI 차종 분석 & 마케팅 리포트 시스템

## 📌 프로젝트 소개
딥러닝 기반의 차종 예측 결과에 LLM(Groq-Llama3.3)을 결합하여, 단순 분류를 넘어 비즈니스 마케팅 전략까지 제안하는 차세대 AI 분석 시스템입니다.

## 📅 개발 기간
- 2026년 01월 09일 ~ 01월 12일 (1인 개발)

## ✨ 주요 기능
### 1. 하이브리드 AI 파이프라인 (CNN + LLM)
- **AI 해석 레이어:** Groq LLM(Llama-3.3-70b)을 활용하여 분류 결과에 대한 지능형 분석 수행
- **마케팅 인텔리전스:** 예측된 차종 정보를 기반으로 타겟 고객군 및 마케팅 전략 제안

### 2. 고성능 비동기 아키텍처
- **비동기 호출:** `asyncio` 기반으로 LLM API를 호출하여 서비스 응답 속도 최적화
- **확장성 설계:** LLM 분석 기능을 클래스 단위로 모듈화하여 모델 교체 및 기능 추가 용이
- **보안 강화:** API Key 관리 및 환경 변수(`.env`) 분리 적용

### 3. 서비스 지향적 인터페이스
- **Gradio 전환:** 기존 Streamlit에서 Gradio로 변경하여 더 직관적이고 인터랙티브한 예측 UI 구현
- **재현 가능성:** 학습/예측/분석 로직의 완전한 분리로 신뢰도 높은 실험 구조 구축

## 🛠 기술 스택
- **LLM:** Groq API (Llama-3.3-70b)
- **Deep Learning:** TensorFlow, Keras
- **Asynchronous:** asyncio
- **UI Framework:** Gradio
